# Woodrover_HIIT
App for use with the Domyos Woodrower2. Facilitates HIIT rowing

Created with mistral vibe, drawing heavily from ressources found in other github repositories and the official documentation of BLE for Fitness maschines.. Thanks for this.

Created for my own private use, but feel free to use it at will.

Installation
Has to be compiled using the gradlew script which is part of google's AndroidStudio. Sent the created apk to the Android device using adb.
